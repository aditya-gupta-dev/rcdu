# Ownership and resource limits

Each memory worker owns its observations and byte-name arena. A directory has one enumerator, with coarse completion records attached after all workers join. The bounded LIFO queue publishes only after incrementing the outstanding count. Overflow executes cooperatively on the publishing worker, so a full queue cannot deadlock every worker. Completion decrements the count once; an empty queue alone never ends a scan. Worker errors, spawn failure, hook panic, output failure and cancellation stop publication, wake sleepers and join all started workers.

Directory buffers are 8192 bytes. At most 16 queued directories and 16 active ancestor descriptors per worker are retained, lowered according to RLIMIT_NOFILE with reserves for root/terminal/output and transient opens. Deep traversal suspends cursors and reopens descriptor-relative chains with at most two transient descriptors. Reopens verify device/inode before resuming the saved getdents cookie. In a concurrently changing directory, cookies and observations are inherently best effort; a scan is not a filesystem snapshot.

Accounting first reduces ordinary observations in postorder, then reduces each inode identity across all its containing ancestors. Shared usage means observed links inside that ancestor are fewer than the effective nlink. Zero or inconsistent counts use the number observed in the complete imported/model tree. Detached records are unreachable and never contribute. All bytes/items saturate; blocks are limited to the original 60-bit representation and multiply by 512 with saturation.

Imports reject empty, NUL, slash, dot and dotdot child names, and names over 32768 bytes. Root names may contain slashes for readonly imports; actions additionally require an absolute root without raw dot/dotdot components. JSON has a 1 MiB token bound, 4096 tree depth and 128 levels for unknown extension values. Binary enforces 24-bit record/block offsets and compressed lengths, 40-bit physical offsets, 56-bit references, 64 MiB index length, checked non-overlapping indexed ranges, 4096 imported depth, and sibling/tree cycle checks. The reader retains up to eight decompressed blocks with a 64 MiB combined budget. Every record/name is copied before a cached block may be evicted. A single very wide indexed listing still needs memory proportional to its children; lazy mode avoids loading unrelated subtrees.

Refresh constructs a replacement before publishing changes. It compacts the entire reachable model to reclaim abandoned observations, then restores current location and selection by byte names. This trades temporary old+replacement+compacted memory for straightforward identity and lifetime rules. Repeated refresh does not retain old generations. The full rebuild cost is measured separately from ordinary scans. Browser state owns IDs only until replacement; saved locations use raw paths.

Built-in deletion reopens and verifies known directories, never follows directory symlinks, and unlinks only known children. Partial errors/abort retain remaining observations. Confirmed unlinking updates matching hardlink counts; then a refresh obtains authoritative surviving metadata. Custom commands run with tty restored and a quoted byte target via an environment variable. Only ENOENT proves the target disappeared; permission and I/O errors remain errors.

Terminal operations belong to one thread. Termios/alternate-screen restoration is guarded on normal exit, errors and panic. SIGINT/SIGTERM/SIGHUP signal only an atomic flag; normal control flow joins workers and restores the terminal. Output and browsing use `/dev/tty` independently of stdin/stdout. Resize is checked on each frame; ANSI rendering targets modern Linux terminals and is intentionally visually different from the ncurses reference.
